Первая версия сайта: https://products-store.hexlet.app/

Вторая версия сайта: https://products-store-v2.hexlet.app/

## О проекте

Ручное тестирование учебного интернет-магазина Hexlet Store в двух версиях: основной прогон на [первой версии](https://products-store.hexlet.app/) и регрессионное тестирование на [второй версии](https://products-store-v2.hexlet.app/).

**Окружение:** Windows 11 26H2 (сборка 26300.9711), Google Chrome 155.0.8059.80, Firefox 159.0.

## Что тестировалось

Каталог и пагинация, карточка и страница товара, поиск, фильтры (категория, бренд, наличие), корзина, оформление заказа, переключение языка (русский / английский). Отдельно проверены нефункциональные требования: работа без перезагрузки страницы, ошибки в консоли и ответы 4xx/5xx, скорость загрузки (3G, Lighthouse), нагрузка на 500 пользователей (Apache JMeter), HTTPS и XSS, адаптивная вёрстка 375–1920 px и поворот экрана.

### Итоги регресса

Вторая версия прогнана по тем же 122 тест-кейсам, что и первая: 89 pass, 33 fail. Упавших кейсов на 4 больше, чем в первой версии.

**Исправлено во второй версии (5 дефектов):**
- у английского языка в меню появилась иконка флага;
- поиск по одним пробелам больше не ломает выдачу;
- в корзине пропала горизонтальная прокрутка;
- элементы каталога больше не перекрывают друг друга на узких экранах;

**Новые дефекты (3):**
- кнопка «Следующая» пропадает, если на странице меньше 30 товаров: каталог обрывается на 4 странице, а с фильтром по категории или со снятым «В наличии» пагинация пропадает совсем;
- при поиске без результатов показывается весь каталог вместо сообщения «Ничего не найдено!»;
- переход по кнопке «Store» в шапке перезагружает страницу.

**Не исправлены с первой версии (22):** в том числе ошибка 500 при оформлении заказа и сообщение об успешном заказе при этой ошибке, отсутствие рейтинга в карточке, поиск только по текущей странице, сброс фильтров и языка, непереведённые надписи, загрузка 15.29 с на 3G и оценка Lighthouse 74 при требовании не ниже 90.

**Нагрузка, 500 пользователей:** 163 361 запрос, 95-й перцентиль — 35 мс, все ответы быстрее 2 с. Ошибок 0.58% (502 и 503, в основном на 6-й минуте теста). Требование выполнено, но в первой версии ошибок не было совсем.

## Установка

Клонировать репозиторий:

```bash
git clone https://github.com/yourapology/qa-engineer-js-from-scratch-project-84.git
cd qa-engineer-js-from-scratch-project-84
```

Для просмотра тест-кейсов, отчётов и баг-репортов ничего устанавливать не нужно: это YAML-файлы, они открываются в любом редакторе или прямо на GitHub.

Для ручных проверок нужны браузеры:
- Google Chrome 155.0.8059.80 (Lighthouse встроен в DevTools)
- Firefox 159.0

Для повторного запуска нагрузочного теста:
- Java 17 или новее
- [Apache JMeter 5.6.3](https://jmeter.apache.org/download_jmeter.cgi): скачать zip-архив и распаковать рядом с папкой репозитория

## Использование

### Файлы в репозитории

| Файл / папка | Что внутри |
|---|---|
| `requirements.yml` | требования: функциональные, нефункциональные, неявные (66 шт.) |
| `test-cases.yml` | тест-кейсы, по ним прогонялись обе версии сайта |
| `testing-report.yml` | статусы кейсов (pass / fail) на первой версии |
| `bugreports.yml` | баг-репорты по первой версии |
| `regress-report.yml` | статусы кейсов и баг-репорты на второй версии |
| `load-test.jmx` | план нагрузочного теста для первой версии |
| `load-test-v2.jmx` | план нагрузочного теста для второй версии |
| `Screenshot/` | скриншоты ошибок, на них ссылаются баг-репорты |
| `logs/` | логи нагрузочных тестов на 500 пользователей для обеих версий |

### Как читать результаты

1. Требования — `requirements.yml`.
2. Тест-кейсы — `test-cases.yml`. У каждого кейса в поле `requirement` указано требование из `requirements.yml`.
3. Статусы — `testing-report.yml` (первая версия) и `regress-report.yml` (вторая версия). Названия кейсов в отчётах совпадают с названиями в `test-cases.yml`.
4. Дефекты — `bugreports.yml` (первая версия) и `regress-report.yml` (вторая версия). В каждом баг-репорте есть ссылка на скриншот из папки `Screenshot/`, в баг-репортах регресса указано, новая это ошибка или она не исправлена с первой версии.

### Нагрузочный тест

Запуск из корня репозитория (рядом должна лежать папка `apache-jmeter-5.6.3`), 500 пользователей, разгон 2 мин, удержание 10 мин.

Первая версия:

```bash
java -jar ..\apache-jmeter-5.6.3\bin\ApacheJMeter.jar -n -t load-test.jmx -Jthreads=500 -Jrampup=120 -Jduration=720 -Jsummariser.interval=30 -l logs\results-500-users.jtl -j logs\jmeter-500-users.log -e -o logs\report-500-users
```

Результат: 163 933 запроса, 0% ошибок, 95-й перцентиль — 23 мс. Требование выполнено. HTML-отчёт открывается из `logs/report-500-users/index.html`.

Вторая версия:

```bash
java -jar ..\apache-jmeter-5.6.3\bin\ApacheJMeter.jar -n -t load-test-v2.jmx -Jthreads=500 -Jrampup=120 -Jduration=720 -Jsummariser.interval=30 -l logs\results-500-users2.jtl -j logs\jmeter-500-users2.log
```

Результат: 163 361 запрос, 0.58% ошибок (502 и 503), 95-й перцентиль — 35 мс, все ответы быстрее 2 с. Требование выполнено. Результаты лежат в `logs/results-500-users2.jtl`, лог запуска — в `logs/jmeter-500-users2.log`.
